# EYLF Assistant Starter

A starter MVP for an AI assistant that helps ECTs and educators write observations, link to EYLF 2.0 outcomes, and suggest follow-up experiences.

## MVP Features
- Landing page for educators
- Observation input form
- Demo output generator
- EYLF outcome suggestions
- Follow-up learning experience suggestions

## Run locally
```bash
npm install
npm run dev
```
