# ECEC Documentation & Assessment Platform

## Mission
Help Australian educators and ECTs create high-quality documentation, assessment and planning faster while maintaining EYLF alignment.

## Target Users
- Educators
- Lead Educators
- Educational Leaders
- ECTs
- Centre Managers

## Core Features
- Daily Journal
- Individual Observation
- Learning Story
- Weekly Program
- Transition Statement
- Summative Assessment
- Incident Report

## Future Features
- Learning goal tracking
- Developmental progression tracking
- Family contributions
- School readiness reports
- PDF export
- Saved drafts and history

## Product Positioning
This product should be positioned as an AI ECEC Documentation and Assessment Platform, not only an observation generator.
